# Scrum Master Tool — Pilot Getting Started

This guide explains how to connect Jira data to the Scrum Master Tool pilot.

## Before you start

You need:

- Access to your company's Jira
- VPN or internal network access if Jira is not publicly reachable
- A Jira Personal Access Token (PAT)
- Google Chrome or Microsoft Edge
- Node.js 18 or newer
- The pilot access PIN provided to you

> Privacy note: Jira data is stored in the workspace folder on your computer. Do not share your Jira token with anyone.

## 1. Create a Jira Personal Access Token

1. Open Jira and sign in.
2. Open your profile / account settings.
3. Find **Personal Access Tokens** or **Manage personal access tokens**. The exact wording can vary by Jira installation.
4. Select **Create token**.
5. Give it a clear name, for example `Scrum Master Tool`.
6. Choose an expiry date if your Jira requires one.
7. Create the token and copy it immediately.

Keep the token private. You will paste it into Terminal when refreshing Jira data.

## 2. Connect to VPN / internal network

If your Jira is only available inside your company network, connect to VPN first.

Quick check: open Jira in your browser. If Jira is reachable, continue.

## 3. Sign in to Scrum Master Tool

Open:

`https://pilot.scrummastertool.com`

Enter the 5-digit pilot PIN provided to you.

## 4. Create and select a workspace

1. Create an empty folder on your computer, for example:

   `Documents/ScrumMasterTool`

2. In Scrum Master Tool, open **Workspace Setup**.
3. Choose the folder you created.
4. Allow the browser to read and write the folder when asked.
5. Add your team.
6. Add and save the Jira JQL for that team.

Example JQL:

```text
project = SOL
```

Use your team's real Jira project/filter JQL. The JQL must be saved before running the Jira refresh helper.

## 5. Check the generated helper files

The workspace should contain files similar to:

```text
ScrumMasterTool/
├── renew-team.command
├── sm-tool/
│   └── jira-pull.mjs
└── teams/
    └── your-team/
```

The helper files are generated by the web app. Do not edit them manually.

## 6. Refresh Jira data — macOS

The current pilot Jira refresh helper is supported on macOS.

1. Open **Terminal**.
2. Type `zsh ` including the trailing space.
3. Drag `renew-team.command` from Finder into the Terminal window.
4. Press **Enter**.

The command will look similar to:

```bash
zsh "/Users/yourname/Documents/ScrumMasterTool/renew-team.command"
```

The helper will show available teams:

```text
Select team to refresh:
1) TEAM A
2) TEAM B
Team number(s):
```

Enter the number of the team you want to refresh. You can also select multiple teams when offered by the helper.

If asked for the Jira URL, enter your Jira base URL, for example:

```text
https://jira.company.net
```

When prompted for:

```text
Jira token:
```

paste the Personal Access Token created in step 1 and press **Enter**.

Terminal may show nothing while you paste/type the token. This is normal — token input is hidden.

The helper then loads Jira issues and changelog history. Depending on the amount of Jira data, this can take a few minutes.

A successful refresh ends with:

```text
Jira refresh complete. Return to the web app and refresh workspace data.
```

### Windows

The browser application can be used on Windows, but the current pilot Jira refresh launcher is not yet packaged for Windows. Windows Jira refresh support is still under development. Do not try to run `renew-team.command` in Windows Command Prompt or PowerShell.

## 7. Load the refreshed data in the app

1. Return to `pilot.scrummastertool.com`.
2. Make sure the same workspace is selected.
3. Open the dashboard.
4. Select **Recalculate**.

After recalculation, the dashboard should show the metrics available from your Jira data, including metrics such as Throughput, Cycle Time, SLE, Aging WIP, Bug Ratio, Velocity, Time in Status, Bottleneck and Flow Efficiency when the required source data is available.

## Updating Jira data later

You do not need to recreate the workspace or team.

1. Connect to VPN/internal network.
2. Run `renew-team.command` again.
3. Select the team(s).
4. Enter your Jira token.
5. Return to the app and select **Recalculate**.

## Troubleshooting

### Jira cannot be reached

Check that:

- VPN/internal network is connected
- Jira opens in your browser
- the Jira URL is correct
- the Personal Access Token is valid

### No team appears in the helper

Open **Workspace Setup** in the app and make sure the team exists and has a saved JQL.

### Metrics do not change after Jira refresh

Return to the app and select **Recalculate** after the helper finishes.

### Node.js error

The current helper requires Node.js 18 or newer. Check with:

```bash
node --version
```
